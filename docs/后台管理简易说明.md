# 网站后台管理简易说明

## 1. 登录后台

1. 打开：[https://scotty-goldenbell.com/admin/login](https://scotty-goldenbell.com/admin/login)
2. 输入管理员密码。
3. 点击「登录后台」。

> 密码请妥善保管，不要发给其他人。

## 2. 新增藏品

1. 点击左边「藏品管理」。
2. 点击「新增藏品」。
3. 填写基本资料：
   - **主要分类**：选择推杆、杆套、球包或配件。
   - **网址别名**：只用小写英文、数字和短横线，例如 `scotty-cameron-newport-2`。
   - **品牌、型号**：必填。
   - **推出年份**：不知道可以留空。
   - **繁体中文、简体中文、英文**：点开各语言区域，填写标题和介绍。
4. 选择藏品状态：
   - **可供洽购**：可以购买或询价。
   - **已预留**：已为客人保留。
   - **已售出**：已经卖出。
   - **私人珍藏・非卖品**：只展示，不出售。
   - **未公开**：只保存在后台，访客看不到。
5. 选择价格显示：
   - **隐藏价格**：网站不显示价格。
   - **显示金额**：直接填正常金额。例如 HK$35,000 就填 `35000`，不用换算成分。
   - **欢迎询价**：让客人联系询价。
   - 货币通常填 `HKD`。
6. 上传照片：
   - 点击「选择文件」，最多 12 张。
   - 可用 JPEG、PNG 或 WebP，每张小于 12 MB。
   - 第一张是封面图。可用「设为主图」或左右箭头调整顺序。
7. 如果要立即给访客看，状态不能是「未公开」，并勾选「发布至网站」。
8. 点击「储存藏品」。

> 不确定时：状态选「未公开」，先不勾选「发布至网站」，保存后再慢慢检查。

## 3. 编辑现有藏品

1. 点击左边「藏品管理」。
2. 在列表中点击要修改的藏品。
3. 修改文字、状态、价格或照片。
4. 点击「储存藏品」。
5. 可点右上角「预览」检查网页效果。

## 4. 复制或删除藏品

- **复制**：在编辑页底部点「复制」。复制品会先保存为私人草稿。
- **删除**：在页底输入该藏品的完整「网址别名」，再点「删除」。

> 删除后无法恢复，照片也会删除。不确定时，改为「未公开」或取消「发布至网站」即可。

## 5. 查看客人咨询

1. 点击左边「客户查询」。
2. 查看客人的姓名、联系方式和留言。
3. 处理后更改状态：
   - `new`：新咨询
   - `contacted`：已联系
   - `closed`：已完成
4. 可在「Internal note」写内部备注，客人看不到。
5. 点击「Update」保存。

## 6. 修改网站设置

1. 点击左边「设置」。
2. 可修改品牌名称、标志文字、默认语言、联系邮箱和所在地。
3. 点击「保存设置」。

## 7. 退出后台

使用完毕后，点击左下角「退出登录」，尤其是使用公用电脑时。

## 最简单的记法

**新增：藏品管理 → 新增藏品 → 填资料 → 上传照片 → 发布至网站 → 储存藏品**

**修改：藏品管理 → 点选藏品 → 修改 → 储存藏品**
